# CUET Computer Club

Official website and management platform for CUET Computer Club.

## Project Structure

- `frontend/` — Public website and user interface
- `backend/` — REST API, authentication, database and business logic

## Technology Stack

### Frontend
- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Fetch API

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Development

The frontend and backend are maintained as separate applications.

Development will follow a controlled phase-by-phase workflow.
